# Citation GIF generator (Papers, Please style)

Simple Flask app that generates a small animated GIF resembling an in-game citation/stamp.

Requirements
- Python 3.8+
- Install dependencies:

```powershell
python -m pip install -r requirements.txt
```

Run:

```powershell
python cli.py --output path/to/citation.gif
```

Help:
```powershell
python cli.py -h
```
